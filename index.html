// How It Works

Just describe what you need.

OpenHands takes your description and handles the rest — planning, coding, testing, and shipping.

01

Describe Your Task

Tell OpenHands what you want in plain language. Build a feature? Fix a bug? Refactor code? It understands natural language and context.

02

It Plans & Executes

OpenHands breaks your request into actionable steps, creates a plan, and starts working through the terminal — writing code, running commands, and iterating in real time.

03

Self-Corrects & Iterates

When things fail, OpenHands reads the output, diagnoses the issue, and adapts. It loops until the task is complete — no hand-holding required.

04

Delivers Working Code

The result is clean, tested, committed code. OpenHands can open pull requests, update documentation, and hand off exactly what you asked for.

from openhands import Agent, LLM

# Create your AI engineer
agent = Agent(
  llm=LLM(model="claude-sonnet"),
  max_steps=20,
  verbosity="debug",
)

# Tell it what to build
agent.run("Add user authentication to this Flask app")
